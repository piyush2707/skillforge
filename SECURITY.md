# Security Policy

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected version, impact, and a minimal reproduction when safe to do so.

## Safe use

SkillForge's MVP creates files and performs structural validation; it does not execute generated scripts. Skills may contain instructions or code from untrusted sources. Review generated content before using it with an agent that can access files, credentials, a shell, or external services.
